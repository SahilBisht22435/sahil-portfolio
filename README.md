# Sahil Bisht - Interactive Portfolio

A responsive, interview-ready personal portfolio built with HTML, CSS and JavaScript.

## Features
- Responsive layout
- Dark/light mode with localStorage
- Mobile navigation
- Typing/role animation
- Scroll progress indicator
- Reveal-on-scroll animations
- Active navigation highlighting
- Project filtering
- Contact links
- GitHub Pages compatible

## Files
- index.html
- style.css
- script.js
- assets/

## Local testing
Open `index.html` directly in a browser, or use the VS Code Live Server extension.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload/push these files to the `main` branch.
3. Open repository Settings → Pages.
4. Select `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.
